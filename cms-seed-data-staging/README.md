# CMS Staging Seed Data

This folder contains staging payloads for the Kitchen vertical.

The local `cms` folder in this checkout does not include a Strapi `src/api` source tree,
so these files keep the content model decisions explicit until the real Strapi source or
database seed script is restored.

Use the same slugs in Strapi and the frontend:

- Vertical: `kitchen`
- Categories:
  - `kitchen-faucets-sinks`
  - `kitchen-surfaces-backsplashes`
  - `kitchen-storage-hardware`
